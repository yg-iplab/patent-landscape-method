# 02 母集団と名寄せ

会社の出願を J-PlatPat から集め、同じ会社の別表記をそろえ、あとから同じ数字を再現できる形で記録します。
ここで作った母集団の質が、以降の図と読みをすべて決めます。

- 入力：`01` の `design.md`（出願人の候補、期間、技術の範囲）
- 出力：`name_map.csv`（名寄せ表）、`jplatpat/search_log.md`（再現ログ）、`jplatpat/results.tsv` または出力した CSV
- 使う道具：J-PlatPat（特許・実用新案検索）、特許庁「特許情報取得API」（番号が分かってから）

---

## 1. J-PlatPat の使い方の前提

- 人が画面で行う操作と同等の範囲だけを使います。ロボットや大量の自動取得は、J-PlatPat の「利用上のご案内」で禁止されています（`05` §4）
- 検索結果の一覧は、ログインなしで見られます。**CSV の出力にはログインが必要**で、利用者本人が行います
- 画面は SPA（ページを切り替えずに中身を書き換える作り）で、URL を直接開くとエラーになることがあります。トップから「特許・実用新案」→「特許・実用新案検索」の順に開きます

## 2. 論理式で検索する

論理式入力のタブに、1本の式で入力します。式は必ず記録します（§5）。

| 目的 | 論理式の例 |
|---|---|
| 出願人で絞る | `[{出願人名}/AP]` |
| OR（同じ括弧の中で `+`） | `[{社名A}/AP+{社名B}/AP]` |
| AND（括弧どうしを `*`） | `[{出願人名}/AP]*[{語}/AB]` |
| 除外（`-`） | `[{出願人名}/AP]-[{語}/TX]` |

主なフィールドコード：`AP` 出願人・権利者、`TI` 名称、`AB` 要約、`CL` 請求の範囲、`FI` FI、`TX` 全文。
出願人は `AP` です（`PA` は無効で、「論理式の指定が間違っています」になります）。
コードがわからないときは、「選択入力」で項目を選んで「条件を論理式に展開」を押すと、画面が正しい式を出します。

文献種別は、日本企業の出願を見るなら「国内文献」だけにして、外国文献のチェックを外します。外し忘れると件数が膨らみます。

### FI（技術分類）を式に入れるとき

FI を主グループ（スラッシュの前まで）で止めた形は、書式エラーになります。
サブクラス（例：`A61K`）か、サブグループまで書いた形（例：`A61K39/395`）にします。

### 3,000件の壁

検索結果が3,000件を超えると、「検索結果が3000件を超えたため表示できません」となり、一覧が出ません（企業名だけの式は、出願が多い会社ではすぐ超えます）。
そのときは次の順で絞ります。

1. 日付で分割する（§3）
2. 技術語を `*[{語}/AB]` などで AND する
3. FI を `*[{分類}/FI]` で AND する

目標は、1回の検索が3,000件を大きく下回ることです。年に分けて複数回に分け、あとで足し合わせます。

## 3. 日付の指定：公知日で指定して、出願日で切る

論理式入力で選べる日付の種類は「公知日/発行日」だけです（2026年10月時点で確認）。出願日では指定できません。
公知日は、出願から約1年半後に付く日です。次のようにします。

1. 範囲は「開始年の1月1日〜出力日（今日）」にします（例：10年分なら `{開始年}0101` 〜 `{出力日}`）
2. 右端を前年末などで切らない。切ると、直近に公開された過去年の出願（例：2〜3年前に出願され、今年公開されたもの）が漏れます。実地では、右端を前年末にして約15件を取りこぼしました
3. 出力した CSV の「出願日」の列で、集計に使う期間（`design.md` の期間）に切り直します

## 4. CSV の出力と読み込み

- 国内文献と外国文献は、別のファイルで出ます。日本企業の分析では国内文献を中心にします
- **国内文献の CSV には、共同出願人が全員入っています**。ステージ（審査の状態）や要約の列もあります。一覧の画面では出願人は筆頭だけで、共同出願は「他」と表示されます。共同出願人は、まず CSV から取ります
- 要約の列があるので、出力した元の CSV は再配布しません（この手順のリポジトリでも `.gitignore` で除外しています）
- 読み込むときの注意：
  - FI の欄は、展開記号が別のカンマ区切りで混ざることがある
  - 出願人の欄に全角のコンマが入ることがある
  - 複数のファイルを連結する前に、出願番号の重複がないか確かめる（同じ出願が二重に入っていれば、`ipl_aggregate.py` は出願番号で除きます）
- 検索結果は、公開が進み、名義変更が反映されると日々変わります。**CSV は同じ日にまとめて出し、件数には出力日を添えて書きます**

## 5. 再現ログ（`search_log.md`）

あとで第三者が同じ母集団を作り直せるように、検索ごとに次を書きます。

```markdown
## 検索 N
- 論理式：
- 文献種別：国内／外国
- 日付指定：種類（公知日）・範囲
- ヒット件数：
- 年ごとの内訳／FI ごとの内訳：（結果一覧の上部に出る数字をそのまま）
- 取得日時：
- 取得した件数：
- 除外したもの・理由：
```

検索式・基準日・件数のない数字は、集計にも文章にも使いません。

## 6. 名寄せ表を作る

同じ会社が、正式名・略称・英語名・旧社名・子会社名で出てきます。名寄せ表（`name_map.csv`）で、どの表記を誰にまとめるかを決めて記録します。

```csv
表記,統合先,区分,根拠,メモ
{正式名},{会社名},本体,有価証券報告書 {年度} 表紙,
{略称・英語名},{会社名},本体,,
{旧社名},{会社名},旧社名,{社史・沿革の頁},{変更年}
{子会社名},{会社名},子会社,有価証券報告書 {年度}「関係会社の状況」,
{まとめない会社},未統合,関連会社,,持分法など。件数は別に出す
```

- 区分：`本体`／`子会社`／`旧社名` は自社側として数えます（`ipl_aggregate.py` の既定）。それ以外は「相手」として共同出願の集計に出ます。集計時に `--company` で会社名を渡し、統合先をその会社名にした行も自社側になります
- **まとめなかった会社は「未統合」と明記します**。まとめなかったことが分かれば、読み手が件数を割り引いて読めます
- 根拠は、有価証券報告書の「関係会社の状況」を基本にします

### 名寄せで起きやすいこと

- **部分一致で無関係の会社が混ざる。** 短い社名や一般的な語を含む社名で出願人検索をすると、同じ語を含む別の会社が入ります。出願人名の一覧（重複を除いたもの）を作り、1つずつ目で確かめます。名寄せ表に「検索語」と「混ざりの確認」の列を足しておくと追跡できます
- **子会社の漏れ。** 有価証券報告書の関係会社の一覧に加えて、過去5年の子会社化・吸収分割・清算の発表（会社のプレスリリース）も確かめます。買収した会社の出願が別の名義で残っていることがあります
- **事業の承継。** 事業の承継（合併・会社分割・事業譲渡など）があると、承継元がした出願のうち名義変更が反映されたものは、承継先の名義で検索結果に出ます。自社が出した出願に、受け継いだ出願が混ざるということです。出願日と承継の時期を照らし、受け継いだ出願が多い年を「自社の出願の増加」と読まないようにします。承継元を自社側として扱うか相手として扱うかを決め、名寄せ表のメモに書きます
- **個人の出願人。** 外国人の個人は、片仮名の「姓 名」で出ることがあります。筆頭の出願人が個人になる出願もあります。共同出願人を種類別に数えるときは、個人を別に扱います
- 名寄せ表は、集計の結果に出る「名寄せ表に無かった表記」を見て育てます（`03`）

## 7. 番号が分かってからの補完

J-PlatPat の一覧では、書誌（共同出願人など）や経過が足りないことがあります。番号が分かった出願に限って、特許庁の「特許情報取得API」で補います。

| 何を | 使うもの | 上限の目安 |
|---|---|---|
| 共同出願人（CSV に無いとき） | 書誌情報の取得 | 公式の利用上限の内側。件数が多いときは分けて |
| 重要候補（3件程度）の経過 | 経過情報の取得（拒絶理由・補正・分割など） | 1回の作業で20回程度 |

- API は、キーワード検索ができません。母集団は J-PlatPat で作り、番号のリストを API に渡します
- 経過情報の呼び出しは1日あたりの回数に上限があります（2026年10月時点で確認した範囲で、1日800回）。公式の最新の案内を見てから使います
- 取得ツールによっては、「分割出願 N件」の数に元の出願自身が含まれ、1件多く出るものがあります。数えるときは中身を確かめます
- この手順では、特許庁APIを呼ぶスクリプトは含めていません（各自の環境で、公式の仕様に沿って用意します）

### 重要候補の選び方

「重要」と呼ぶのではなく、次の特徴を持つ出願を「重要候補」として並べます。理由を1行ずつ書き、評価の呼び名は付けません。

- 分割出願が多い
- 拒絶理由に対して補正して登録に至っている
- 海外ファミリー（複数の国への出願）が広い
- `design.md` の重点領域の中心にある

### 医薬品の場合

医薬品の特許は、承認までの期間を補う「存続期間の延長登録」（特許法67条4項）が付くことがあります。経過情報で、延長登録の出願の有無を見ます。
ただし、満了日そのものは、外から断定しません。延長の有無・期間・対象は、個別の確認が必要です。「経過情報から読める範囲」と書きます。
