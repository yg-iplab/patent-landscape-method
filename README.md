# 企業1社の特許出願を、開示資料と重ねて読む手順

公開されている特許情報（J-PlatPat・特許庁API）と、企業の開示資料（有価証券報告書・統合報告書・論文）を重ねて、1社の出願の動きと連携の形を読むための手順とスクリプトです。
問いを立て、出願を集めて名寄せし、集計して図にし、仮説にまとめ、公開前に検査するところまでを順に書いています。

> 公開情報だけで作った個人の学習用の分析です。対象企業とは関係がありません。

## 手順の流れ

```
会社を知る → 問いを立てる → 母集団と名寄せ → 補完 → 文献
   → 集計・図 → 仮説 → 検査

  会社を知る    事業・将来像・研究開発・知財の開示を公開資料で読む
  問いを立てる  将来像と今の姿の差から、問いを1つに絞る
  母集団と名寄せ J-PlatPat の論理式で出願を集め、同じ会社の別表記をそろえる
  補完          番号から経過・共同出願人などを補う
  文献          有価証券報告書・統合報告書・論文・雑誌を重ねる
  集計・図      年・技術分類のシェア・共同出願人を集計して図にする
  仮説          事実・読み・仮説に分けて書く
  検査          裏取り・論理・読み手の目で点検する
```

| 手順 | 内容 |
|---|---|
| [01 問いの立て方](method/01_問いの立て方.md) | 将来像と今の姿の差から問いを1つ立て、調査目的を3つの型に置く |
| [02 母集団と名寄せ](method/02_母集団と名寄せ.md) | 論理式、3,000件の壁、日付の指定、名寄せ表、再現ログ、番号からの補完 |
| [03 集計と図](method/03_集計と図.md) | 年・技術分類のシェア・共同出願人、図の注記、質の近似、事実・読み・仮説 |
| [04 非特許情報](method/04_非特許情報.md) | 有価証券報告書（EDINET）、統合報告書、論文・雑誌の重ね方 |
| [05 限界と注意](method/05_限界と注意.md) | 見えないもの、断定しない書き方、利用ルール、検査 |

## 中身


## 使い方（概要）

1. `method/01` で問いを立て、`./work/{会社名}/design.md` に書く
2. `method/02` に沿って J-PlatPat で母集団を作り、名寄せ表 `name_map.csv` と再現ログを残す
3. `python3 scripts/ipl_aggregate.py --input ./work/{会社名}/jplatpat/results.tsv --name-map ./work/{会社名}/name_map.csv --company "{会社名}" --out ./work/{会社名}/charts`
4. `method/04` で事業の数字と文献を重ね、`method/03` §6 の形で事実・読み・仮説に分ける
5. `method/05` のチェックリストで点検する

J-PlatPat の操作は、人が画面で行う範囲に限ります（自動の大量取得はしません）。

塩野義製薬の見本です（応募資料ではなく、手順の実例）。2016〜2025年に出願された国内の公開特許と、有価証券報告書・統合報告書を重ねています。最終確認日は 2026-10-11 です。

- [提出版（Markdown）](demo/塩野義製薬/report_v1.md)
- [付録（Markdown）](demo/塩野義製薬/appendix_v1.md)
- PDF：[`デモ_塩野義製薬_公開特許と事業の分析_202610.pdf`](demo/塩野義製薬/デモ_塩野義製薬_公開特許と事業の分析_202610.pdf)（4ページ）と [付録](demo/塩野義製薬/デモ_塩野義製薬_公開特許と事業の分析_202610_付録.pdf)（8ページ）

提出版では、共同研究の相手を「企業1社」と書いています。社名は付録にだけ出します。J-PlatPat から出力した元の CSV（要約や個人の出願人名を含む）は載せていません。本文が指している図は `demo/塩野義製薬/charts/` にあります。

## 使っている公開データ

J-PlatPat（INPIT）、特許庁「特許情報取得API」、EDINET（金融庁）、国立国会図書館サーチ、J-STAGE、Google Patents。有償のデータベースは使っていません。
